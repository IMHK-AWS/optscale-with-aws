# Agentic AI meets open source FinOps for autonomous cloud cost action:

Cloud cost management shouldn't stop at dashboards. This demo explores how open source FinOps tooling and agentic AI architecture can be combined to build a system that autonomously observes cost anomalies, reasons through optimization strategies, and executes remediation,  closing the loop without human intervention. A technical walkthrough for engineers and architects looking to move FinOps from reactive reporting to intelligent, self-driving operations.

for this demo, it will be optscale for the finops tool and i will embed AWS Quick Suite Chat Agent (not amazon q) into it to facilitate agentic query on finops

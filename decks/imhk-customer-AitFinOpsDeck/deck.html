Builder lessons — what I'd tell myself
Four honest takeaways
MCP changes the integration game
A standard protocol for tool calls means you write the connector once and any agent can use it. No more bespoke glue code per vendor.
Human-in-the-loop is non-negotiable
The agent that deletes things autonomously is the agent nobody trusts. Starting with recommendation-only builds adoption faster than full automation.
Open source gives you the data layer
Self-hosting OptScale means the AI agent can query live billing data directly — no API rate limits, no per-query cost, no data leaving your perimeter.
Alibaba Cloud is the gap nobody fills
Every Western FinOps tool treats Alibaba as an afterthought. This is a real competitive moat — especially in APAC markets where Alibaba spend is significant.
